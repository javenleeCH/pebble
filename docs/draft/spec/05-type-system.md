# 05 类型系统与 Schema 推导

## 5.1 类型集合

### 标量类型

| 类型 | 字面量 | 说明 |
|---|---|---|
| `i64` | `42`, `-10` | 64 位有符号整数 |
| `f64` | `3.14`, `-0.5` | 64 位浮点数 |
| `bool` | `true`, `false` | 布尔 |
| `string` | `"hello"` | UTF-8 字符串 |

### 可选类型

`?T` 表示该字段可能为 `null`，如 `?string`、`?i64`。

- `null` 只能出现在可选类型位置。
- 可选值参与算术 / 拼接运算时，结果类型为 `?T`；是否短路处理 `null` 由算子实现定义，编译期只校验类型标签。
- 比较 `x == null` 仅在 `x` 为可选类型时合法。

### 行类型（Row）

一行 = 有序的 `字段名 → 类型` 映射，即表的 Schema。行类型只在编译器内部使用，用户无需手写类型声明。

## 5.2 类型推导与提升

### 算术提升

| 操作数组合 | 结果类型 |
|---|---|
| `i64` 与 `i64` | `i64` |
| `i64` 与 `f64`（任意侧） | `f64` |
| `f64` 与 `f64` | `f64` |
| 含 `?T` | 结果为对应可选类型 |

### 其他规则

- `+` 两侧均为 `string` → `string`；其余字符串与数值混合 → 类型错误，无隐式转换。
- 比较运算结果恒为 `bool`；参与比较的两侧类型必须兼容。
- 逻辑运算操作数必须为 `bool`。
- 内置函数返回类型见 [04-expressions.md](04-expressions.md)。

## 5.3 Schema 自动推导

### 源算子

- `Table(path)` / `MemoryTable(name)`：从数据源元信息（文件 Schema / UniExtract 元数据 / 宿主内存表）读取输入 Schema。

### 变换算子

| 算子 | 输出 Schema 规则 |
|---|---|
| `filter(pred)` | 与输入 Schema 完全一致。 |
| `map(proj)` | 输入字段保留，叠加记录字面量中的字段；**同名字段被投影覆盖**。 |
| `select(...)` | 仅保留显式列出的字段，顺序与列出顺序一致。 |
| `distinct()` | 与输入 Schema 一致。 |
| `sort(...)` | 与输入 Schema 一致。 |
| `take(n)` | 与输入 Schema 一致。 |
| `join(other, on: cond)` | 左行字段 ∪ 右行字段；两侧同名字段不自动合并，必须以别名限定引用。 |

**规范澄清**：计划书将 `map` 描述为「投影 / 新增字段」。v1 明确为**叠加覆盖**语义（保留未被投影的输入字段）；需要严格裁剪列时使用 `select`。

### 聚合算子

| 算子 | 输出 Schema 规则 |
|---|---|
| `group_by(cols)` | 输出行仅含分组键字段。 |
| `agg(...)` | 分组键字段 ∪ 各聚合绑定字段。 |

聚合函数返回类型：

| 聚合函数 | 参数类型 | 返回类型 |
|---|---|---|
| `count()` | 无参（计数行数） | `i64` |
| `count(x)` | 任意 | `i64`（非空计数） |
| `sum(x)` | `i64` → `i64`；`f64` → `f64` | 同参数标量类型 |
| `min(x)` / `max(x)` | 可比较标量 | 同参数类型 |
| `avg(x)` | `i64` / `f64` | `f64` |

## 5.4 静态校验

编译期完成全部检查，错误定位到源码位置：

| 检查项 | 报错条件 |
|---|---|
| 字段存在性 | 引用了当前行 Schema 中不存在的字段 |
| 类型匹配 | 运算符 / 函数 / 聚合的操作数类型不兼容 |
| 运算符支持 | 对不支持的类型使用某运算符（如字符串相减） |
| join 键类型 | `on` 条件两侧比较字段类型不一致 |
| 分支类型统一 | `if` 各分支类型不一致 |
| 可选类型 | 非可选字段被赋 `null` |
| 别名冲突 | 同一流水线内源别名重复，或与字段名冲突 |

## 5.5 类型标注的边界

- v1 不支持用户手写类型标注、不支持自定义类型、不支持泛型。
- 类型信息全部由编译器从源 Schema 与表达式推导得出。
- 推导无法确定时（如空表无元数据），报编译期错误并提示数据源缺少 Schema 元信息，而不是运行时容错。
