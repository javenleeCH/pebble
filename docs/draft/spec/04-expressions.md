# 04 表达式

表达式只出现在算子参数中，用于谓词、投影、聚合计算。语言中**没有语句**：除流水线骨架外，一切计算都由表达式描述。

## 4.1 运算符优先级

从高到低（同级左结合，`^` 级除外）：

| 级别 | 运算符 | 结合性 | 说明 |
|---|---|---|---|
| 1 | `.` 字段访问、`()` 调用、`()` 括号 | 左 | 原子表达式 |
| 2 | 一元 `-`、`!` | 右 | 取负、逻辑非 |
| 3 | `*` `/` `%` | 左 | 乘、除、取模 |
| 4 | `+` `-` | 左 | 加、减；字符串拼接仅 `+` |
| 5 | `==` `!=` `>` `<` `>=` `<=` | 左 | 比较 |
| 6 | `&&` | 左 | 逻辑与 |
| 7 | `||` | 左 | 逻辑或 |

括号可改变优先级。示例：

```pebble
u.age >= 18 && !u.banned
u.first + " " + u.last
(a + b) * c
```

## 4.2 表达式形式

### 字段访问

```pebble
u.age
orders.amount
```

- `别名.字段名`：引用某一行的字段。
- 裸标识符：在单行上下文中解析为当前行字段；在 `agg` 上下文中可解析为分组键或已绑定的聚合结果。
- 字段不存在由语义层报错（见 [05-type-system.md](05-type-system.md)）。

### 算术运算

`+` `-` `*` `/` `%`，操作数为 `i64` / `f64`；类型提升规则见类型系统章节。

### 比较运算

`==` `!=` `>` `<` `>=` `<=`。相等比较支持同类型标量；大小比较支持数值与字符串。

### 逻辑运算

`&&` `||` `!`，操作数必须为 `bool`。短路语义仅用于可读性，不影响纯变换结果。

### 字符串拼接

`+` 两侧均为 `string` 时执行拼接；一侧数值一侧字符串属于类型错误，不做隐式转换。

### 内置函数调用

| 函数 | 签名 | 说明 |
|---|---|---|
| `abs(x)` | `(i64) -> i64` / `(f64) -> f64` | 绝对值 |
| `round(x)` | `(f64) -> f64` | 四舍五入到最近整数（返回 f64） |

v1 内置函数为白名单制；用户不可自定义函数。

## 4.3 Lambda 表达式

Lambda 是算子的**表达式模板**，不是一等函数：

```pebble
.filter(|row| row.status == "valid")
.map(|row| { value = row.num * 2 })
```

约束：

1. 只能接收一个参数（当前行）。
2. 函数体只能是表达式或记录字面量。
3. 只能引用：形参字段、字面量、内置函数；不能捕获外部可变状态。
4. 不能嵌套定义 Lambda。
5. 不能赋值给标识符、不能作为返回值、不能在算子间传递。

### 记录字面量

`map` 的函数体为记录字面量时，花括号内是一组 `字段 = 表达式` 绑定：

```pebble
.map(|u| {
  full_name = u.first + " " + u.last,
  birth_year = 2026 - u.age
})
```

记录字面量的输出 Schema 推导规则见 [05-type-system.md](05-type-system.md)。

## 4.4 if 条件表达式

仅支持**值选择型 if 表达式**，必须有 `else` 分支，所有分支类型一致：

```pebble
level = if u.score >= 90 { "A" }
        else if u.score >= 60 { "B" }
        else { "C" }
```

规则：

- 语义等价于数学分段函数。
- 分支内只能写表达式，不能写语句、不能启动子流水线。
- 禁止顶层 `if` 选择整条流水线（红线 3）。
- 分支类型不一致由语义层报错。

## 4.5 表达式禁止事项

- 禁止赋值（`=` 只出现在记录 / 聚合绑定左侧）。
- 禁止逗号表达式、语句块。
- 禁止函数定义、递归调用。
- 禁止访问当前行 Schema 之外的字段。
