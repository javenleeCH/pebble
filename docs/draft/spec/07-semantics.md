# 07 语义规则

## 7.1 数据流 DAG 语义

- 程序是一张算子节点 + 数据依赖边的 DAG；v1 语法形态为单条线性流水线，内部 HIR 仍按 DAG 组织，以便后续分支复用与算子融合。
- 每个算子读取上游行集，产出新行集；算子之间不共享可变状态。
- 执行顺序仅由数据依赖决定。编译器可在不改变最终结果的前提下：
  - 下推 `filter` 到数据源附近；
  - 合并相邻投影；
  - 重排无依赖的算子；
  - 选择并行执行策略。

## 7.2 纯变换与确定性

- 除终端算子外，所有算子满足**引用透明**：相同输入必然产生相同输出，不读取外部状态、不产生外部影响。
- 程序结果对同一数据源是确定的；不依赖系统时间、随机数、环境变量。
- 算子内部实现可以维护临时工作状态（如排序缓冲区、哈希表），但不暴露给语言层，不构成可变全局状态。

## 7.3 副作用边界

| 层级 | 允许的副作用 |
|---|---|
| 变换 / 聚合算子 | 无 |
| `write` | 写本地文件 |
| `collect` | 回传宿主内存 |
| `print` | 写标准输出 |

终端算子只能位于流水线末尾；编译器拒绝终端之后再接算子的程序。

## 7.4 有限性与终止性

- 所有数据源必须是有限集合；语言层不提供无限流、不提供分批拉取语法。
- 所有迭代由内置算子隐式完成，迭代次数静态可确定为「输入集合行数」。
- 语言不提供：`for` / `while` / `loop`、递归定义、函数自应用、无界递归调用。

## 7.5 Lambda 语义约束

- Lambda 是算子内的逐行表达式模板，闭包只绑定形参，不捕获环境中的可变绑定。
- Lambda 不可作为一等值：不可赋值、不可存储、不可传递、不可返回。
- Lambda 不可嵌套；函数体不可定义新的 Lambda。
- 这些约束同时在语法文法（03）与语义检查（08）两层强制。

## 7.6 条件表达式语义

- `if` 表达式等价于数学分段函数：按自上而下的分支顺序求值，取第一个条件为真的分支；全部不真时取 `else`。
- 分支只能是表达式；不能在分支内启动子流水线或修改流水线结构。
- 所有分支结果类型必须统一；可选类型在分支间按 05 章规则对齐。

## 7.7 空值（null）语义

- `null` 表示字段缺失，仅存在于可选类型 `?T`。
- 含 `null` 的运算结果类型保持可选；具体遇 `null` 的取值行为（跳过 / 透传 / 报错）由算子实现定义，v1 规范不做强制，后续版本在算子手册中逐算子明确。
- 聚合函数对 `null` 的处理：`count(x)` 不计 `null`；`sum` / `min` / `max` / `avg` 忽略 `null`。

## 7.8 顺序与排序保证

- 未显式 `sort` 时，行的输出顺序不做保证；优化器可重排。
- `sort` 之后的顺序由排序键决定；`take` 只在已排序结果上取前 N 才有确定含义。
- 并列排序键的行顺序不稳定，不保证与输入顺序一致。

## 7.9 设计红线的语义层落地

| 红线 | 语义层强制手段 |
|---|---|
| 无通用循环 / 递归 | 文法无对应产生式；无函数定义与调用递归路径 |
| 无一等函数 | Lambda 不进入值类型系统；赋值 / 传参 / 返回位置类型检查拒绝 |
| 无顶层控制流 | `if` 只能出现在表达式位置；流水线结构不可由条件选择 |
| 无可变全局状态 | 算子接口按纯函数设计；语义层拒绝环境读写 |
| 无无限流 | 源算子类型只接收有限集合；无拉取 / 订阅语法 |
