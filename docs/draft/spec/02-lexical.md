# 02 词法规范

## 2.1 字符集

源码使用 UTF-8 编码。词法分析按 Unicode 字符处理；字符串字面量内部允许任意 Unicode 标量值，标识符仅允许 ASCII（见 2.3）。

## 2.2 空白与注释

- **空白**：空格（U+0020）、制表符（U+0009）、换行（U+000A）、回车（U+000D）。空白在词法层被丢弃，不参与语义；字符串内部除外。
- **注释**：单行注释，以 `//` 开头，直到行尾。v1 不提供块注释。

```pebble
// 这是一行注释
Table("a.parquet") // 行尾注释
```

## 2.3 标识符

- 文法：`letter | "_"` 后接若干 `letter | digit | "_"`。
- `letter` = `A–Z` / `a–z`；`digit` = `0–9`。
- 标识符大小写敏感。
- 与关键字冲突时按关键字处理（见 2.4）。

```pebble
user_id, full_name, Age, _tmp   // 合法
123a, user-id                   // 非法
```

## 2.4 关键字

| 关键字 | 用途 |
|---|---|
| `true` | 布尔字面量真 |
| `false` | 布尔字面量假 |
| `null` | 空值（可选类型专用） |
| `if` | 值选择型条件表达式 |
| `else` | 条件表达式分支 |
| `on` | `join` 固定绑定名（`on = expr`） |
| `asc` | 升序排序限定符（默认） |
| `desc` | 降序排序限定符 |
| `as` | 数据源别名声明、`select` 派生列命名 |

保留但 v1 不启用：`filter`、`map`、`join` 等算子名属于**内置算子名**，不是关键字；用户标识符不得与内置算子名重名（语义层报错）。

## 2.5 字面量

### 整数

- 文法：`"-"? [0-9]+`；负号在表达式层作为一元运算符处理，词法层只识别无符号数字。
- 默认类型 `i64`；超出 i64 范围在语义层报错。

```pebble
42, 0, 1000000
```

### 浮点数

- 文法：`"-"? [0-9]+ "." [0-9]+`；必须含小数点。
- 默认类型 `f64`。

```pebble
3.14, -0.5, 1.0
```

### 字符串

- 双引号包裹：`"..."`。
- 转义序列：`\"`（双引号）、`\\`（反斜杠）、`\n`（换行）、`\t`（制表符）。
- v1 不支持字符串插值、不支持原始字符串。

```pebble
"hello", "Li", "a \"quoted\" word"
```

### 布尔与空值

```pebble
true, false, null
```

`null` 只能出现在可选类型位置；非可选字段被赋 `null` 在语义层报错。

## 2.6 运算符与分隔符

| 类别 | 词法单元 |
|---|---|
| 算术 | `+` `-` `*` `/` `%` |
| 比较 | `==` `!=` `>` `<` `>=` `<=` |
| 逻辑 | `&&` `||` `!` |
| 结构 | `(` `)` `{` `}` `[` `]` `,` `.` `:` `=` |

说明：
- `=` 仅用于记录字段绑定、聚合绑定与 `join` 的 `on =`（`name = expr`），**不是**赋值运算符；语言中不存在赋值语句。
- `|` 已不再是词法单元：v1 废除 Lambda `|param|` 后该符号不再出现。
- 词法最长匹配：`>=` 不可拆为 `>` `=`。

## 2.7 词法错误

| 代码 | 含义 |
|---|---|
| `LEX-001` | 非法字符（不在字符集与词法表内） |
| `LEX-002` | 字符串未闭合（行尾未遇到结束引号） |
| `LEX-003` | 非法转义序列 |
| `LEX-004` | 数字字面量格式非法（如 `.5`、`1.`） |

诊断输出格式见 [08-diagnostics.md](08-diagnostics.md)。
