# 08 错误与诊断规范

诊断全链路基于 Ariadne 0.15.0 输出源码级彩色报错；Chumsky 解析阶段产出的 Span 贯穿语义层，保证错误位置可回溯到源码。诊断文本可以本地化，错误码与触发条件属于稳定契约。

## 8.1 严重级别

| 级别 | 含义 | 编译行为 |
|---|---|---|
| `Error` | 确定的语法 / 语义 / Schema 错误 | 中止编译，不生成后端代码 |
| `Warning` | 可疑但可编译（MVP 预留，暂不产生） | 继续编译 |
| `Note` | 补充说明，可附带在 Error 上 | 不影响编译 |

输入校验与宿主执行失败使用 RUN 执行诊断，不伪装成源码类型错误，也不得转换为字段 null。

## 8.2 编译期错误分类与错误码

### 词法错误（LEX）

| 代码 | 含义 |
|---|---|
| `LEX-001` | 非法字符 |
| `LEX-002` | 字符串未闭合 |
| `LEX-003` | 非法转义序列 |
| `LEX-004` | 数字字面量格式非法 |

### 语法错误（PAR）

| 代码 | 含义 |
|---|---|
| `PAR-001` | 期望算子、分隔符或字面量，遇到意外 token |
| `PAR-002` | 终端算子之后接续了算子 |
| `PAR-003` | extend 参数不是记录字面量，或记录字面量出现在其他表达式位置 |
| `PAR-004` | `if` 缺少 `else` 分支，或 if 条件/分支未使用规定文法 |
| `PAR-005` | agg 绑定右侧不是 MVP 允许的直接聚合调用 |
| `PAR-006` | select 的复合表达式缺少 `as name`，或无 as 项不是字段引用 |
| `PAR-007` | join 未使用固定绑定 `on = expr` |

### 语义错误（SEM）

| 代码 | 含义 |
|---|---|
| `SEM-001` | 字段不存在于当前解析域 |
| `SEM-002` | 类型不匹配（操作数、参数或绑定位置） |
| `SEM-003` | 运算符不支持该类型 |
| `SEM-004` | 源别名重复；源别名与字段同名不属于错误 |
| `SEM-005` | 算子位置非法，如分组后的 agg 位置不满足语法约束 |
| `SEM-006` | join 右表不是当前语法允许的源算子 |
| `SEM-007` | if 分支类型不能按可选类型规则统一 |
| `SEM-008` | null 用于非可选位置，或独立 null 无法确定基础类型 |
| `SEM-009` | 使用已废除的 Lambda 形参或函数值语法 |
| `SEM-010` | filter、join on、if 条件或 having 不是 bool/?bool |
| `SEM-011` | 裸字段名称在当前 Schema 中歧义，必须别名限定 |
| `SEM-012` | 字段超出作用域，如 select 后访问裁剪字段、agg 后访问输入行字段 |
| `SEM-013` | extend/agg RHS 引用同一记录的兄弟绑定 |
| `SEM-014` | 同一 extend 记录或 agg 绑定列表内名称重复 |
| `SEM-015` | 使用 NaN、±∞ 字面量，或数值字面量超出 MVP 有限 f64 值域 |
| `SEM-016` | 编译期可确定的除零、模零、整数溢出或非有限 f64 运算结果 |
| `SEM-017` | 聚合函数位于 agg 之外、聚合嵌套，或全局 agg 的组级部分引用输入行 |

动态 checked-null 不是诊断：只有编译期可确定的非法常量使用 `SEM-016`；运行时动态定义域失败按语义返回 null。

### Schema 错误（SCH）

| 代码 | 含义 |
|---|---|
| `SCH-001` | 数据源缺少锁定/注册的 Schema 元信息，无法推导 |
| `SCH-002` | join 连接键两侧类型不兼容 |
| `SCH-003` | select、分组键或聚合输出的名称发生禁止的重复 |
| `SCH-004` | 多个 group_by 键去限定后重名；MVP 不自动改名 |
| `SCH-005` | 实际输入 Schema 与 Schema lock/宿主注册 Schema 不一致 |
| `SCH-006` | 进入要求唯一列名的输出边界时仍存在重名字段 |

`SEM-011` 指向一次具体歧义引用；`SCH-006` 指向未消歧的输出边界，两者不得混用。

## 8.3 执行与输入诊断（RUN）

RUN 诊断表示程序已通过编译，但本次执行的前置条件或宿主能力失败：

| 代码 | 含义 |
|---|---|
| `RUN-001` | f64 输入含 NaN 或 ±∞，违反 MVP 有限值输入约束 |
| `RUN-002` | 输入 Schema 在执行前校验失败或发生变化 |
| `RUN-003` | 终端 IO、宿主输出或能力边界失败 |
| `RUN-004` | 执行被取消、OOM 或资源配额耗尽 |

`RUN-001/002` 必须在正常表达式求值前报告。RUN 错误不得静默变成 null，也不得仅因某后端接受该输入而被忽略。

## 8.4 诊断结构

每条诊断包含：

- **错误码**：如 `SEM-001`。
- **严重级别**：见 8.1。
- **消息**：一句话说明问题。
- **源码位置**：文件、起止行号与列号（Span）；RUN 无源码位置时至少给出输入/能力身份。
- **标签片段**：在源码片段上标注出错区间，可附多个子标签。
- **提示（hint）**：修复建议或当前作用域可用字段/算子列表。

作用域错误的 hint 必须列当前可见字段，不得列已经被 select 裁剪或 agg 隐藏的输入字段。歧义错误应列出候选限定名。

## 8.5 输出示例

```text
error[SEM-001]: 字段 `birth` 不存在于当前解析域
  ┌─ examples/cond.pebble:4:29
  │
4 │   .extend({ age = 2026 - u.birth })
  │                            ^^^^^ 未知字段
  │
  提示: 当前可用字段: id, first, last, age
```

```text
error[SCH-002]: join 连接键类型不一致
  ┌─ examples/join.pebble:6:51
  │
6 │   .join(Table("orders.parquet") as o, on = u.id == o.uid)
  │                                                   ^^^^^ 类型 i64 与 string 不可比较
  │
  提示: 左侧 `u.id: i64`，右侧 `o.uid: string`
```

```text
error[SEM-011]: 裸字段 `id` 存在歧义
  ┌─ examples/join.pebble:7:12
  │
7 │   .filter(id > 0)
  │           ^^ 可指 u.id 或 o.id
  │
  提示: 请改写为 `u.id > 0` 或 `o.id > 0`
```

## 8.6 诊断流程

1. **词法阶段**：产出 LEX 错误，尽量恢复到下一个行首继续扫描。
2. **解析阶段**：错误恢复解析，产出 PAR 错误与部分 AST。
3. **语义阶段**：沿流水线逐算子做解析域、Schema 与类型检查，产出 SEM/SCH 错误；一条诊断对应一处主要源码区间。
4. 任一编译期 Error 存在时，不进入 HIR lowering 或任何后端代码生成。
5. **执行前置校验**：验证 Schema lock 与 f64 有限值约束，失败时产出 RUN 诊断且不提交正常执行。
6. 同一源码错误不得因目标后端不同而出现/消失；后端能力诊断必须使用独立类别，不能替代语言诊断。
