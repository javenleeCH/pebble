# 08 错误与诊断规范

诊断全链路基于 Ariadne 0.15.0 输出源码级彩色报错；Chumsky 解析阶段产出的 Span 贯穿语义层，保证错误位置可回溯到源码。

## 8.1 严重级别

| 级别 | 含义 | 编译行为 |
|---|---|---|
| `Error` | 确定的语法 / 语义 / Schema 错误 | 中止编译，不生成后端代码 |
| `Warning` | 可疑但可编译（v1 预留，暂不产生） | 继续编译 |
| `Note` | 补充说明，可附带在 Error 上 | 不影响编译 |

## 8.2 错误分类与错误码

### 词法错误（LEX）

| 代码 | 含义 |
|---|---|
| `LEX-001` | 非法字符 |
| `LEX-002` | 字符串未闭合 |
| `LEX-003` | 非法转义序列 |
| `LEX-004` | 数字字面量格式非法 |

### 语法错误（PAR）

| 代码 | 含义 |
|---|---|
| `PAR-001` | 期望算子、分隔符或字面量，遇到意外 token |
| `PAR-002` | 终端算子之后接续了算子 |
| `PAR-003` | Lambda 形参非法（数量不为一 / 标识符非法） |
| `PAR-004` | `if` 缺少 `else` 分支 |
| `PAR-005` | `agg` 绑定右侧不是聚合调用 |

### 语义错误（SEM）

| 代码 | 含义 |
|---|---|
| `SEM-001` | 字段不存在于当前行 Schema |
| `SEM-002` | 类型不匹配（操作数 / 参数 / 赋值位置） |
| `SEM-003` | 运算符不支持该类型 |
| `SEM-004` | 源别名重复或与字段名冲突 |
| `SEM-005` | 算子位置非法（如 `agg` 未紧跟 `group_by`） |
| `SEM-006` | `join` 右表不是源算子 |
| `SEM-007` | `if` 分支类型不一致 |
| `SEM-008` | `null` 用于非可选类型位置 |
| `SEM-009` | Lambda 违规：嵌套、捕获外部状态、出现在一等值位置 |

### Schema 错误（SCH）

| 代码 | 含义 |
|---|---|
| `SCH-001` | 数据源缺少 Schema 元信息，无法推导 |
| `SCH-002` | `join` 连接键两侧类型不一致 |
| `SCH-003` | 投影 / 聚合字段类型与既有字段冲突 |
| `SCH-004` | `join` 两侧同名字段未用别名限定，引用歧义 |

## 8.3 诊断结构

每条诊断包含：

- **错误码**：如 `SEM-001`。
- **严重级别**：见 8.1。
- **消息**：一句话说明问题。
- **源码位置**：文件、起止行号与列号（Span）。
- **标签片段**：在源码片段上标注出错区间，可附多个子标签。
- **提示（hint）**：修复建议或当前作用域可用字段 / 算子列表。

## 8.4 输出示例

```text
error[SEM-001]: 字段 `birth` 不存在于当前行 Schema
  ┌─ examples/cond.pebble:4:31
  │
4 │   .map(|u| { age = 2026 - u.birth })
  │                              ^^^^^ 未知字段
  │
  提示: 当前可用字段: id, first, last, age
```

```text
error[SCH-002]: join 连接键类型不一致
  ┌─ examples/join.pebble:6:29
  │
6 │   .join(Table("orders.parquet") as o, on: u.id == o.uid)
  │                             ^^^^^^^ 类型 i64 与 string 不可比较
  │
  提示: 左侧 `u.id: i64`，右侧 `o.uid: string`
```

## 8.5 诊断流程

1. **词法阶段**：产出 LEX 错误，尽量恢复到下一个行首继续扫描。
2. **解析阶段**：Chumsky 错误恢复解析，产出 PAR 错误与部分 AST。
3. **语义阶段**：沿流水线逐算子做 Schema 推导与类型检查，产出 SEM / SCH 错误；一条诊断对应一处源码区间，不做跨文件合并。
4. 任一 `Error` 存在时，不进入 HIR  lowering 与后端代码生成。
