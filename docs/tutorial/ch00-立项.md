# 第 0 章 立项：从「我想造语言」到 rationale 与五条红线

> 对应提交：`3bccd59`（补写）。本章没有代码，但它决定了后面每一行代码的生死。

## 本章目标

1. 学会用**一页 rationale** 把「我想造一门语言」变成可执行、可否决的决策集合。
2. 理解**红线**的作用：不是口号，而是后续每个特性的评审闸门。
3. 亲历一次真实的定位拷问：我们做了两轮专家评审，第一版定位被推翻重来。

## 为什么立项要先写 rationale

造语言最大的风险不是写不出编译器，而是**没有边界**：什么都能加的语言等于什么都做不好。rationale 的作用是在写第一行代码之前，把「做什么、给谁做、明确不做什么」拍板成文，让每个后续特性都有一个可以对表的裁判。

Pebble 的 rationale（[`rationale.md`](../rationale.md)）回答四个问题：

1. **类别**：DSL（面向离线批结构化数据），不是通用编程语言；
2. **痛点**：不可信脚本攻击面大、审批逻辑与实际执行难以绑定、SQL/通用语言的行为依赖后端；
3. **不可替代理由**：三条支柱——Schema 即代码即哈希、计划即证明物、必然终止零副作用；
4. **红线**：五条，任何特性评审先过这五条。

## 被否决的第一版（这是本章最重要的教训）

第一版定位是「更好的批处理 DSL」：链式语法、编译期校验、非图灵完备、可导出 LaTeX。两轮专家评审（[`review-2026-11-23.md`](../review-2026-11-23.md)、[`review-r2-2026-11-23.md`](../review-r2-2026-11-23.md)）逐条拆掉了它：

| 原卖点 | 评审结论 |
|---|---|
| 链式语法 = 数据流 DAG | PRQL/Polars/dplyr 都有，零复制壁垒 |
| 编译期 Schema 校验 | dbt/DuckDB 已覆盖；不 pin Schema 就没有证明力 |
| 非图灵完备 | SQL 核心本来就非图灵完备；它也不是安全保证 |
| LaTeX 可数学化 | `sort/take` 不属于关系代数；「漂亮的公式」≠ 证明 |

结论：**「更好用」撑不起立项，必须换一个「别人给不了」的楔子**。于是定位 pivot 成「可信数据变换」：

> 把源码、Schema 快照、规范化逻辑计划、生成的执行工件和运行回执连接成**可独立核对的证据链**。

同时明确了「不承诺什么」（这一段救了项目很多次）：

- 终止 ≠ 有界内存 ≠ 沙箱；
- 哈希 ≠ 执行结果正确；
- LaTeX ≠ 数学证明。

## 五条红线：立项的可执行形式

红线是把定位翻译成**可判定的拒绝规则**（[`docs/design-decisions.md`](../design-decisions.md) §2.2）：

1. **总性**：无用户递归/循环/无界迭代；数据源有限——终止性不冒充资源安全；
2. **一阶纯函数**：无一等函数、无 UDF——UDF 是「可数学化」的头号威胁（黑盒不可入代数）；
3. **线性数据流**：单入口单出口，`if` 只能值选择——不能在分支里选择整条流水线；
4. **受控效应**：输入输出只能经显式能力边界——`Table` 是输入能力、`write` 是受控终端；
5. **语义封闭**：禁止「由实现定义」进入规范——这条是第二轮评审新增的，也是后端适配（第 6 章）的伏笔。

**怎么用**：此后每个特性提案都过这张表。比如「要不要加 UDF」——红线 2 直接否决，除非未来引入「带契约与预算的受信函数」，那也必须是显式修订红线而不是偷偷放行。

## 立项产出物清单（你可以照抄的顺序）

1. `rationale.md`：一页纸，定位/用户/取舍/边界；
2. 样例代码：5~10 个 `.pebble` 文件先于文法存在（「样例先行」，语言长什么样由样例说了算）；
3. EBNF 草案：允许随时改，但每次改样例必须同步；
4. 红线五条：可判定的拒绝规则。

## 练习

1. **给你的语言写 rationale**：选一个你熟悉的领域（配置、游戏脚本、报表……），写出一页纸。要求：「不可替代理由」一节里至少有一条是现有主流工具**结构上给不了**的——写不出来就说明该换楔子。
2. **红线压力测试**：假设有人提议「给 Pebble 加用户自定义聚合函数」，用五条红线逐条审它；哪几条被触发？如果要支持，最小的合规路径是什么（提示：受信注册 + 契约 + 预算）？
3. **找反例**：在 `docs/draft/spec/` 里找出一处与 `docs/design-decisions.md` 矛盾的历史残留（如果找到，这是 bug，欢迎提交 issue）。
